# Quick Installer Creation Guide - Smart Orders Desktop

## 🎯 Simple 3-Step Process

Since you want me to do this for you, here's the absolute simplest way to create your .exe installer:

---

## Step 1: Download Inno Setup (2 minutes)

**Direct Download Link**: https://jrsoftware.org/isdl.php

**What to download**: 
- Look for: **"Inno Setup 6.x.x"** (latest stable version)
- File name: `innosetup-6.x.x.exe`
- Size: ~3 MB
- Click the download link

**Or use this direct link**:
```
https://files.jrsoftware.org/is/6/innosetup-6.2.2.exe
```

---

## Step 2: Install Inno Setup (1 minute)

1. Run the downloaded `innosetup-6.x.x.exe`
2. Click "Next" → "Next" → "Install"
3. Wait 30 seconds
4. Click "Finish"

**That's it!** Inno Setup is now installed.

---

## Step 3: Create Your Installer (1 minute)

### Option A: Double-Click Method (Easiest!)

1. **Navigate to**:
   ```
   c:\Users\ASUS\Desktop\Smart-order\
   ```

2. **Double-click**:
   ```
   installer_script.iss
   ```
   This will open Inno Setup Compiler automatically!

3. **Press F9** (or click Build → Compile)

4. **Wait 30-60 seconds**

5. **Done!** Your installer is ready at:
   ```
   c:\Users\ASUS\Desktop\Smart-order\installer_output\
   SmartOrdersDesktop-v1.2.0-Setup.exe
   ```

### Option B: Command Line Method

Open PowerShell and run:

```powershell
cd c:\Users\ASUS\Desktop\Smart-order
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer_script.iss
```

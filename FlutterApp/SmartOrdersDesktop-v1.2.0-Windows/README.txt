## 📦 Installation Instructions

### Quick Start (No Installation Required)

This is a **portable application** - no installation needed!

1. **Extract** this folder to any location on your computer
2. **Double-click** `smart_orders_desktop.exe` to run the application

- Desktop
- C:\Program Files\SmartOrdersDesktop
- Any folder of your choice

## 🔧 Troubleshooting

### Application won't start
**Solution**: 
- Make sure all files are in the same folder
- Check if Windows Defender is blocking the app
- Right-click the .exe → Properties → Unblock

### Missing DLL errors
**Solution**:
- Ensure all .dll files are in the same folder as the .exe
- Download Visual C++ Redistributable from Microsoft

### Slow performance
**Solution**:
- Close other applications
- Check system resources (Task Manager)
- Restart the application

### Can't login
**Solution**:
- Use the test credentials provided above
- Check if caps lock is on
- Try copying and pasting the credentials

## 🎯 Quick Feature Guide

### Creating an Order
1. Click "Create Order" in the menu
2. Search or filter products on the left
3. Click the + button to add products
4. Edit quantities directly in the table
5. Click "Send Order" when ready

### Using Filters
- **Promotions only**: Shows promotional products
- **In Stock only**: Shows available products
- Both can be used together

### Managing Tabs
- Click menu items to open new tabs
- Drag tabs to reorder them
- Click X to close tabs

## 🚀 Installation Methods

### Method 1: Portable Installation (Recommended)

**For End Users**:

1. **Extract the ZIP file**
   - Right-click `SmartOrdersDesktop-v1.2.0-Windows.zip`
   - Select "Extract All..."
   - Choose destination folder
   - Click "Extract"

2. **Run the Application**
   - Navigate to extracted folder
   - Double-click `smart_orders_desktop.exe`
   - Or double-click `Launch Smart Orders.bat`

3. **Create Desktop Shortcut** (Optional)
   - Right-click `smart_orders_desktop.exe`
   - Select "Send to" → "Desktop (create shortcut)"
   - Rename shortcut to "Smart Orders Desktop"

**Advantages**:
- ✅ No installation required
- ✅ No admin rights needed
- ✅ Can run from USB drive
- ✅ Easy to update
- ✅ No registry changes

## 🔧 Troubleshooting

### Common Issues

**Issue**: "Windows protected your PC" message
**Solution**: Click "More info" → "Run anyway"
**Reason**: Application is not code-signed

**Issue**: Application won't start
**Solution**: 
- Ensure all files are in same folder
- Check antivirus isn't blocking
- Install Visual C++ Redistributable

**Issue**: Missing DLL errors
**Solution**: 
- Re-extract the ZIP file
- Ensure all .dll files are present
- Don't move .exe without other files
